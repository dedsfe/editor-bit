# Cobertura da lista do brief

Primeiro lote de cerca de 30 sons. “Substituto” informa uma adaptação, sem fingir que a gravação tinha a origem solicitada. Os modelos de IA não foram usados para preencher lacunas.

| Necessidade | Entrega / situação |
|---|---|
| Passos na areia | Falta gravação específica; protótipo procedural em `gerador/saida/passos_areia.wav` |
| Passos na terra | `passos_trilha`, gravação de caminhada em trilha; material não identificado rigorosamente |
| Passos na pedra | `passos_pedra`, cinco tomadas de concreto Kenney montadas em sequência, substituto acústico seco |
| Passos na água rasa | Falta gravação específica; protótipo `passos_agua.wav` e respingos reais separados |
| Passos na chuva | Compor passos e chuva; falta tomada específica de piso molhado |
| Sandália de couro | Falta; gravações pesquisadas do Freesound bloquearam download |
| Correndo | Falta tomada real específica; passos de pedra podem ser reprogramados mais próximos, sem afirmar corrida original |
| Ondas calmas | `ondas_calmas` |
| Mar agitado / tempestade | `ondas_calmas` + `chuva_forte_vento` + trovão; falta mar agitado isolado |
| Respingo / splash | `respingo`, `splash_lago` |
| Alguém afundando | `bolhas_afundando`, substituto de bolhas; falta gravação de corpo entrando na água |
| Barco de madeira rangendo | `madeira_tensao` como camada; falta barco dedicado |
| Remo na água | Falta. Candidato SoundBible tinha Sampling Plus 1.0, foi excluído |
| Chuva fraca / forte | `chuva` e `chuva_forte_vento`; baixar ganho não transforma fisicamente uma chuva em outra |
| Trovão perto / longe | `trovao_perto`, `trovao_longe` |
| Vento forte / assobio | `vento_forte`; assobio isolado ainda falta |
| Vento leve EP03 | `vento_leve`, suavização filtrada de vento gravado, preparada para cama distante |
| Multidão sem palavras | `multidao_murmurio`, densificação de vozes e filtro; inteligibilidade reduzida a conferir na escuta |
| Mercado antigo / esquina de dia | `ep03_esquina_mercado`, composição de murmúrio e passos; não registro de mercado histórico |
| Vila de dia | A composição de esquina pode ser atenuada; vila dedicada ainda falta |
| Monte ao amanhecer | `ep03_monte_amanhecer` |
| Noite com grilos | `grilos_noite` |
| Fogueira | `fogueira` |
| Pássaros de manhã | `passaros_manha`, gravação de pássaros depois da chuva usada na cena de amanhecer |
| Galho balançando / quebrando | `madeira_tensao`, `galho_quebrando`; folhas e balanço dedicado ainda faltam |
| Alguém caindo na terra | `impacto_curto` + passos de trilha como substituto; falta corpo em terra gravado |
| Porta de madeira | `porta_madeira` |
| Jarro de barro | `ceramica_contato`, contato de prato como substituto; jarro/quebra dedicados faltam |
| Moedas | `moeda_caindo` |
| Ovelhas | `ovelha` |
| Jumento | Falta gravação comercial verificável baixada |
| Leão rugindo / rosnando | `leao_rugido`, `leao_rosnado` |
| Brilho suave de milagre | `brilho_suave`, ressonância metálica filtrada; manter baixa, pode soar sino se destacada |
| Whoosh | `whoosh_transicao`, movimento físico de ar, curto |
| Impacto de câmera | `impacto_curto` |
| Risada abafada de plateia | `risada_abafada`, risada de ator filtrada; não é uma plateia real |

Próximo lote: Foley de areia/água/sandália, remo, barco, jumento e folhagem. Para o EP03, a maior melhoria seria gravar brisa própria e walla consentido ao ar livre, sem substituir o trabalho já entregue.
